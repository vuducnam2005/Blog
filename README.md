## 🛠️ Hướng Dẫn Cài Đặt & Chạy Cục Bộ

### 1. Yêu cầu môi trường
- Node.js >= 18
- npm hoặc yarn

### 2. Chạy Frontend
```bash
cd frontend
npm install
npm run dev
```
Truy cập: `http://localhost:3000`

### 3. Build Production
```bash
npm run build
```
Thư mục sản phẩm `dist/` đã sẵn sàng để deploy lên Vercel, Netlify hoặc VPS.
